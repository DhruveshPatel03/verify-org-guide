How to publish: GitHub Pages (quick)
1. Create a new GitHub repository.
2. Add the files (index.html and style.css) to the repo root.
3. Commit & push.
4. In repository Settings → Pages, choose the main branch and / (root) as source.
5. Save — GitHub Pages will publish within a minute.

Alternatives: Netlify, Vercel — drag-and-drop site deploy or connect your repo.

Customize the content and links before publishing.
